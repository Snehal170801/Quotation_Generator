1. Prerequisites
Install these first:
Node.js v20 or newer (this project uses v22 — download from nodejs.org)
PostgreSQL (v14+; this project uses v18) — via your OS package manager or postgresql.org/download
Git (only needed if pulling from a repo instead of a zip)
Verify installs:
node --version
npm --version
psql --version
2. Get the project onto the machine
Extract the zip (or git clone) so you end up with:
Quatation-Webapp/
├── Quatation-Backend/
└── Quatation-Frontend/
3. Set up PostgreSQL
Start the Postgres service, then create the database:
sudo systemctl start postgresql   # Linux
# or `brew services start postgresql` on Mac
Set a password for the postgres user and create the database:
sudo -u postgres psql
Inside psql:
ALTER USER postgres PASSWORD 'admin123';
CREATE DATABASE quotation_db;
\q
(You can use any username/password/db name — just make sure it matches step 4.)
4. Configure the backend
cd Quatation-Webapp/Quatation-Backend
Create a .env file:
DATABASE_URL="postgresql://postgres:admin123@localhost:5432/quotation_db?schema=public"
PORT=5000
JWT_SECRET=some_random_secret_here
Install dependencies and set up the database schema:
npm install
npx prisma generate
npx prisma migrate deploy
Seed the admin user and default form fields:
npm run seed:admin
npm run seed:fields
5. Configure the frontend
cd ../Quatation-Frontend
npm install
No .env needed — it auto-detects the backend from the browser's hostname. (Only add one if you want to override the backend URL.)
6. Run both servers
Backend (from Quatation-Backend):
npm run dev
Frontend (from Quatation-Frontend, separate terminal):
npm run dev
7. Access it
Open http://localhost:5173 (or the LAN IP Vite prints, for other devices on the network).
Login credentials (created by the seed script):
Email: admin@quatation.com
Password: Admin@123
After logging in, use Settings → User Management to create real admin/sales accounts, and change/remove this seed account if it's a shared or production-facing machine.
